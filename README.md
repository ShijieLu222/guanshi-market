# 观市 · 全球资产看板

React + D3 市值树图 + Cloudflare Worker。所有前端资源随站点打包，不依赖外部前端 CDN。

## 开发

```sh
npm ci
npm test
npm run build
npm run dev
```

本地入口为 http://127.0.0.1:4173。Node 开发服务提高了响应头容量，以兼容 Yahoo 行情页的公开响应；生产使用 Worker Fetch。

## 外观

右上角可切换深色／浅色主题，选择保存在当前浏览器，刷新后恢复。主题与红绿涨跌配色独立，切换不重启行情请求。

## 数据与口径

- 黄金、白银：Gold API 的 XAU/XAG 国际现货 USD/金衡盎司，源约每30秒更新。
- 人民币克价：USD/oz × USD/CNY ÷ 31.1034768。非金店零售报价。汇率时间独立显示。
- Tech 100：纳斯达克 100 现货指数（^NDX），单位为点，每10秒请求；非交易时段显示最新可得点位与报价时间。不使用期货或 CFD 替代。
- 13只股票：NVDA、SPCX、000660.KS、SNDK、MU、WDC、AMD、INTC、AAPL、GOOGL、MSFT、META、AMZN。
- Yahoo chart 提供真实分时点；公开行情页中的结构化 JSON 提供带时间的常规、盘前、盘后、隔夜价格，以及公司总市值。只解析目标证券，不执行远端脚本。
- 主报价采用时间最新的有效报价。扩展时段涨跌相对最近常规收盘；常规涨跌相对前收盘。隔夜价格不等同于某券商实时可成交买卖价。
- 分时线包含盘前、常规、盘后，不包含隔夜；页面明确分开显示曲线与主报价的时段。
- SK海力士公开KRX源标示约20分钟延迟，股价为KRW。热力图总市值使用USD/KRW换成USD；面积严格按有效市值比例，缺失值不填充。
- 市值是源提供的公司总市值快照，不以隔夜价格自行重估。详细信息保留获取时间。
- 每只股票10秒轮询；金银每30秒刷新；汇率30秒、韩元汇率60秒。服务端短缓存只保存完成的数据，避免跨请求共享未完成任务导致断线后重试卡住；浏览器定时器持续轮询，返回前台或网络恢复时立即重取。
- 新响应不得覆盖时间更新的已显示数据；请求失败保留旧数据并标记。无数据时显示空值，不包含模拟行情。

## 已验证

`npm test` 覆盖换算、排序修复、延迟标记、报价时间检查、最新时段选择、隔夜涨跌基准、公开页目标代码解析、旧响应保护、跨币种市值换算、矩形面积与市值比例。

## 限制

公开源没有端到端实时性保证；页面结构、接口限流或可用性变化可能导致中断。查看每张卡片上的报价时间。若需要交易所级延迟保证，可在 `server/data.js` 中替换为有适当权限的数据服务。

部署身份保存在 `.openai/hosting.json`。保持现有站点ID，后续更新复用该站点。
